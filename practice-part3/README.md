# Практическая работа №1 — часть 3

## Задание 1 — Shape

Абстрактный `Shape` задаёт цвет, признак заливки, площадь и периметр. `Circle`, `Rectangle` и `Square` реализуют эти операции. `ShapeDemo` хранит фигуры в массиве базового типа и показывает полиморфный вызов методов.

Вызов `new Shape()` из примера задания не компилируется, потому что `Shape` абстрактный. Вызовы методов `getRadius()` или `getSide()` через переменную типа `Shape` также не компилируются: таких методов нет в объявлении базового класса. После приведения типа доступны методы подкласса, если объект действительно относится к этому подклассу.

## Задание 2 — Movable

Интерфейс `Movable` реализуют `MovablePoint`, `MovableCircle` и `MovableRectangle`. Прямоугольник хранит две точки и при создании проверяет, что у них совпадают скорости.

Для демонстрации в IntelliJ IDEA запускайте `practice3.shapes.ShapeDemo` и `practice3.movable.MovableDemo` по отдельности.
