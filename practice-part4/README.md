# Практическая работа №1 — часть 4

Решения четырёх заданий. В перечислениях `Season` и `ClothingSize` использованы поля, конструктор, методы и `values()` по примеру `Planet` из приложенного файла.

## Задания

1. `task1` — времена года, средняя температура, описание и сообщение о любимом времени года.
2. `task2` — размеры одежды, интерфейсы мужской и женской одежды, типы вещей и ателье.
3. `task3` — консольный интернет-магазин: демонстрационная авторизация, категории, каталог, корзина и покупка.
4. `task4` — компьютер, его марка и отдельные классы комплектующих.

В интернет-магазине используются демонстрационные данные: логин `student`, пароль `java123`. Их можно поменять в `InternetShop.java`.

Каждый пример запускается отдельно из своей папки исходников. У каждого задания есть класс с методом `main`.

Дополнительный раздел по наследованию и абстрактным классам находится в [части 4.1](../practice-part4.1/README.md).
